资源告警设置

按资源池设置可用库存阈值和通知渠道，及时提醒管理员手动补充账户。

告警规则

每分钟检查一次，可用库存 ≤ 设定阈值时通知。阈值可设为 0；库存恢复后再次不足会重新通知。发送失败每 5 分钟重试。

Telegram 通知

填写 Bot Token 和接收消息的 Chat ID。请先与 Bot 发起对话，或将它加入目标群组并授予发送权限。

如何获取 Chat ID

个人通知：使用查询 ID 的 Bot（更简单）

  1. 打开 @userinfobot，点击 Start（开始），按提示获取你自己的数字 ID。
  2. 将返回的个人数字 ID 填入上方 Chat ID；此方式用于给你本人发送私聊通知。
  3. 再打开上方 Bot Token 对应的告警 Bot，点击 Start 或发送 /start，让告警 Bot 可以向你发送消息。仅启动查询 ID 的 Bot 不够。

@userinfobot 是第三方工具，并非 Telegram 官方 Bot。查询个人 ID 不需要向它提供你的 Bot Token。

群组通知或备用方式：通过 Telegram 官方 API 获取
  1. 个人通知：在 Telegram 中打开你配置的 Bot，点击 Start（开始），或发送 /start。
  2. 群组通知：将这个 Bot 加入目标群组，在群里发送 /start@你的Bot用户名（替换为实际用户名，不需要 Bot 回复），并确保 Bot 有发送消息的权限。
  3. 在浏览器打开 https://api.telegram.org/bot<你的Bot Token>/getUpdates，把 <你的Bot Token> 整段替换为上方 Bot 的真实 Token，保留前面的 bot。
  4. 在返回的 result 中找到刚刚发送的消息，核对 message.chat 中的姓名或群名，复制 message.chat.id 到上方 Chat ID。群组 ID 如带负号，必须完整保留；不要复制 from.id 或 update_id。

如果 result 为空，重新发送上述消息后刷新。如果 Bot 已设置 Webhook，或有其他程序正在读取消息，请从该程序收到的消息中获取 message.chat.id，或使用独立的告警 Bot。
