Resources · capability checks

Resources API 测试台

页面只访问 Manager，由 Manager 使用内网地址转发到 Resources。

GET /v1/google-user

Google User

首次调用会分配账号，之后返回同一邮箱和密码。


    
GET /v1/google-user/access-token
Google Access Token
通过 Domain-Wide Delegation 为当前用户签发短期 token。

    
GET /v1/browser
当前 Browser
创建或复用当前 API Key 的 Browser Session，返回 CDP 和 Live URL。

    
POST /v1/browser/reset
重置 Browser
停止旧 Session 并创建一个新 Browser Session。

    
POST /v1/browser/close
关闭 Browser
只停止当前 Session，保留 Browser profile；下次获取时会使用原 profile 创建 Session。

    
GET /v1/telegram-bot
Telegram Bot
首次调用从资源池固定分配一个 Bot，之后使用同一 API Key 会返回相同 Token。

    
GET /v1/xbox/account
Xbox Bot
首次调用固定分配一个已注册账号；同一 API Key 会持续返回该账号及登录密码。

    
Google 写能力验证
以下操作会真实写入 Gmail 或 Google Drive，执行前请确认测试参数。

    
POST /v1/google-user/test/gmail/send
发送测试邮件

    
POST /v1/google-user/test/drive/folders
创建 Drive 文件夹
文件夹会创建在当前 Google User 的 My Drive 根目录。

  

  
测试结果可能包含 Google/Xbox 密码、Access Token 和 Browser 地址。不要截图或转发响应；测试完成后可清除本页保存的 Key。
